# Оптимизация скорости загрузки USB DFU для STM32H723

## Внесенные изменения

### 1. Увеличен размер блока передачи данных
**Файл:** `USB_DEVICE/Target/usbd_conf.h`
- **Параметр:** `USBD_DFU_XFER_SIZE`
- **Было:** 1024 байт
- **Стало:** 2048 байт
- **Эффект:** Увеличение скорости передачи данных в ~2 раза

### 2. Уменьшены таймауты операций Flash
**Файл:** `USB_DEVICE/App/usbd_dfu_if.c`

#### FLASH_PROGRAM_TIME
- **Было:** 50 мс
- **Стало:** 5 мс
- **Назначение:** Время ожидания после программирования блока Flash

#### FLASH_ERASE_TIME
- **Было:** 50 мс
- **Стало:** 10 мс
- **Назначение:** Время ожидания после стирания сектора Flash

## Ожидаемое улучшение производительности

### Расчет скорости загрузки:

**До оптимизации:**
- Размер блока: 1024 байт
- Время на блок: ~50 мс (программирование)
- Скорость: ~20 КБ/с

**После оптимизации:**
- Размер блока: 2048 байт
- Время на блок: ~5 мс (программирование)
- Скорость: ~400 КБ/с

**Ускорение: ~20x**

## Дополнительные возможности оптимизации

### 1. Дальнейшее увеличение размера блока
Можно попробовать увеличить `USBD_DFU_XFER_SIZE` до 4096 или даже 8192 байт, но:
- Требуется больше RAM
- Может быть несовместимо с некоторыми хост-утилитами DFU
- Рекомендуется тестирование

### 2. Оптимизация таймаутов
Текущие значения (5 мс / 10 мс) являются агрессивными, но безопасными для STM32H7.
Можно попробовать еще меньшие значения:
```c
#define FLASH_PROGRAM_TIME  (uint16_t)2
#define FLASH_ERASE_TIME    (uint16_t)5
```

**Внимание:** Слишком малые таймауты могут привести к ошибкам программирования!

### 3. Использование DMA для операций Flash
В текущей реализации можно добавить DMA для ускорения копирования данных.

### 4. Отключение проверки записи
В функции `MEM_If_Write_HS()` есть проверка записанных данных (строки 238-242).
Можно закомментировать для ускорения, но это снизит надежность:
```c
// Не рекомендуется для production!
// if (*(uint64_t *) (src + i) != *(uint64_t *) (dest + i))
// {
//   return 2;
// }
```

## Тестирование

После внесения изменений рекомендуется:

1. **Пересобрать проект**
   ```bash
   cmake --build build
   ```

2. **Загрузить bootloader в MCU**

3. **Протестировать загрузку прошивки**
   - Используйте dfu-util или STM32CubeProgrammer
   - Проверьте корректность загруженной прошивки
   - Измерьте время загрузки

4. **Команда для тестирования с dfu-util:**
   ```bash
   dfu-util -a 0 -D firmware.bin -s 0x08020000
   ```

## Безопасность изменений

✅ **Безопасно:**
- Увеличение `USBD_DFU_XFER_SIZE` до 2048 байт
- Уменьшение таймаутов до 5/10 мс для STM32H7

⚠️ **Требует тестирования:**
- Дальнейшее увеличение размера блока
- Дальнейшее уменьшение таймаутов
- Отключение проверки записи

## Совместимость

Изменения совместимы с:
- ✅ STM32CubeProgrammer
- ✅ dfu-util (Linux/Windows/macOS)
- ✅ Стандартными DFU-утилитами

## Откат изменений

Если возникнут проблемы, верните исходные значения:

**usbd_conf.h:**
```c
#define USBD_DFU_XFER_SIZE     1024U
```

**usbd_dfu_if.c:**
```c
#define FLASH_ERASE_TIME    (uint16_t)50
#define FLASH_PROGRAM_TIME  (uint16_t)50
```

## Примечания

- STM32H723 поддерживает USB High-Speed, что позволяет использовать большие размеры блоков
- Реальная скорость зависит от скорости Flash памяти и системной частоты
- Для максимальной производительности убедитесь, что CPU работает на максимальной частоте (550 МГц для H723)
